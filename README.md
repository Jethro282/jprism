# JPRISM v0.2

Static GitHub Pages prototype for an inventory and work order management platform.

## Deployment
Upload all root files and the `docs/` directory to the repository root. In GitHub Pages, publish `main` / `(root)`. Open `https://jethro282.github.io/jprism/`.

## Testing
- Open the welcome page and enter demo.
- Inventory: add, edit, search, filter and archive a fictional product.
- Refresh and confirm the change remains in the same browser.
- Export a backup before testing import.
- Confirm the existing placeholder navigation works.

## Limits
Browser-only data; not shared or secure. Browser storage may be cleared. Product opening quantities can be edited directly; a real system will need a transaction ledger. No authentication or audit guarantees. Do not use for real inventory.
